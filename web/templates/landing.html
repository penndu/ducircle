WHAT IT DOES

该自动的自动，该你说了算的你自己定

不要求对方配什么，也不要求你写爬虫。大部分博客，给个首页地址就够了。

一个地址，收下整页友链

输入 /friends/ 这类友链页，自动解析出链接和名字，之后还会定期回看有没有新朋友。

没 RSS 也能抓

Feed → 框架指纹 → 启发式 → 自定义规则，四层依次兜底。实在抓不到，会告诉你卡在哪。

按你的节奏跑

文章和友链各设各的 cron，失败站点自动降频，不去反复打扰已经下线的博客。

一句话摘要 + 推荐分

接大模型给每篇文章写句摘要、打个分，先挑值得读的看。支持填自己的 Key，额度自己掌握。

HOW IT WORKS

三步，然后就不用管了

01 / ADD

把友链页交给它

粘贴友链页地址，或者手动加站点、导入 OPML。/friends/ 一类的页面会自动认出里面的博客。

02 / CRAWL

让它定时去跑

自动发现 RSS、识别博客框架，抓回新文章并去重。哪个站点挂了、失败几次，后台都看得见。

03 / USE

把文章流取回去

拿 API Key 调 /v1/posts，返回标题、链接、站点、摘要和推荐分，前端想怎么排都行。

OPEN API

数据是你的，接口也是开放的

不用把页面嵌进博客，也不用改主题。一个 GET 请求拿到结构化数据，剩下的交给你的前端。

  • API Key 鉴权，随时可重新生成
  • 分页、按站点筛选、按推荐分排序
  • 字段沿用友链朋友圈习惯，老前端少改
