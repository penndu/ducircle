三步接上，不用改主题

整套流程只需要一次 GET，域名、字段都沿用友链朋友圈的习惯，老前端基本不用动。

01 / SIGN UP

注册并添加友链

注册后在后台粘贴 /friends/ 之类的友链页，或手动加站点、导入 OPML，等它抓回第一批文章。

02 / API KEY

拿到你的 API Key

在「设置 → API Key」里生成，随时可以重新生成。每个 Key 只对应自己的数据，租户之间互相看不到。

03 / REQUEST

带着请求头调接口

请求头加 X-API-Key，调 /v1/all 就能拿到文章流。分页用 start / end。

CONVENTIONS

鉴权与约定

请求约定

所有 /v1 接口都要求带 Key，公开页面和后台接口不走这一套。

鉴权头X-API-Key: your_key
基地址{{ base_url }}
数据格式application/json
分页start / end（条数偏移）
排序rule = created | updated | score

常见返回

出错时返回 {"detail": "…"}，中文说明，不甩堆栈。

200请求成功
401API Key 缺失、无效或已重置
422参数不合法，附具体字段说明
429触发限流，稍后重试
500服务端异常，可到服务状态页查看
